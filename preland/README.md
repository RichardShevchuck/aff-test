# Тестовый преленд — колесо фортуны

Живая страница: https://aivagallery.pp.ua
Проверка проброса: https://aivagallery.pp.ua/?subid=12345&clickid=abc&debug=1

## Структура
```
site/
  index.html      
  css/style.css  
  js/params.js   
  js/wheel.js    
```

## Что сделано по пунктам ТЗ
1. **Лендинг** — простая прокладка с колесом фортуны
2. **Чистка** — нет ни одного внешнего скрипта, пикселя, шрифта или CDN. Все запросы идут только на свой домен (проверяется в DevTools → Network). Заголовок заменён.
3. **Деплой** — Nginx на Ubuntu, SSL Let's Encrypt через certbot, редирект HTTP → HTTPS.
4. **Параметры** — `js/params.js`:
   - забирает **все** параметры из адресной строки (subid, clickid, sub1..sub5, fbclid и т.д.);
   - сохраняет их в sessionStorage, чтобы не потерять при перезагрузке без query;
   - дописывает их к ссылке оффера на кнопке «Забрать бонус» (`data-offer`);
   - дублирует `clickid` в `sub1` — частый формат партнёрок (настраивается в `CLICKID_ALIASES`);
   - не перетирает параметры, уже заданные в ссылке оффера;
   - `?debug=1` показывает итоговую ссылку прямо на странице.

Ссылка оффера задаётся в `OFFER_URL` в `js/params.js`.
